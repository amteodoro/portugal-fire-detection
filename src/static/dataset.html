Prepare Training Dataset

Process Sentinel-2/3 and FIRMS data into training-ready tiles and splits.

Automated 4-Step Pipeline:

  1. Matches FIRMS fires to S2 and S3 scenes
  2. Extracts tiles from matched pairs
  3. Creates train/val/test splits
  4. Generates co-located S2+S3 pairs

Smaller tiles work better with Sentinel-3 edge coverage. Same size used for co-located visualizations.

Requires Sentinel-2, Sentinel-3, and FIRMS data to be downloaded first.

Uses config from ml/configs/config.yaml for split ratios

Start model training with prepared dataset.

Long Running Process:

Training can take hours depending on dataset size and hardware. Keep this page open to monitor progress.
